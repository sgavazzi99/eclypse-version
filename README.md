# Eclipse — versions du jeu

**Pour jouer :** téléchargez [Eclipse.exe](https://github.com/sgavazzi99/eclypse-version/raw/main/Eclipse.exe), puis double-cliquez dessus.

Au premier lancement, le lanceur télécharge le jeu (environ 37 Mo), puis le bouton **JOUER** s'allume.
Ensuite, à chaque lancement, il vérifie s'il existe une nouvelle version et ne télécharge que les morceaux qui ont changé.
Sans connexion internet, il lance la dernière version déjà installée.

Windows peut afficher « Windows a protégé votre ordinateur » (programme non signé) : cliquez sur « Informations complémentaires », puis « Exécuter quand même ».

Version actuelle : voir `manifeste.json`.
